# 🃏 Русский Блэкджек (Telegram Bot)

Добро пожаловать в **«Русский Блэкджек»** - Telegram-бота, написанного на Python, где правила классической игры адаптированы под русскую специфику! 

## 🎯 Особенности правил (Русская версия)
В этой версии игры действуют особые правила подсчета очков, которые отличают её от классического казино:
* **Валет** = 2 очка
* **Дама** = 3 очка
* **Король** = 4 очка
* **Туз** = 11 очков (или 1 очко, если сумма превышает 21)
* **Цифровые карты** (от 2 до 10) = по номиналу.

**Цель игры:** набрать 21 очко или ближе к 21, чем дилер.
**Перебор:** больше 21 - ты проиграл.

## 🏗 Архитектура проекта
Проект написан по принципам **чистой архитектуры** (разделение ответственности), код разделен на три слоя:
* `models.py` - **Данные** (классы `Card` и `Deck`). Отвечают только за хранение информации о картах и колоде.
* `services.py` - **Логика игры** (класс `Game`). Здесь живет вся математика: подсчет очков с учетом Тузов, ходы дилера и определение победителя. Слой ничего не знает про Телеграм.
* `bot.py` - **Интерфейс** (Telegram Handlers). Связывает логику игры с кнопками и сообщениями в Telegram.

## 🛠 Технологии
